## 3. 示例代码

## 4. 我遇到的问题

## 学习成果展示

不要只放“学过什么”，还要放“做出了什么”：

- 可运行的代码
- 项目截图或演示视频
- 在线体验地址
- 运行步骤
- 遇到的问题与解决方案
- 下一版准备改进的地方

## 统计规则

- 每次完成一个小主题，就新增一篇 Markdown 笔记。
- 每次写出可运行代码，就放进对应专题目录。
- 每周至少更新一次学习记录。
- 文件名使用小写英文和短横线，例如 `binary-search.md`。
